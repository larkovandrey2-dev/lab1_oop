Лабораторная работа 1 по ООП. Программа работает с динамическим массивом: создаёт, печатает, вставляет и удаляет элементы, изменяет размер, сортирует выбором, выполняет бинарный поиск и разворачивает массив.

Для сборки нужны CMake 3.16+, компилятор C++20 и интернет при первой сборке для загрузки Google Test.

cmake -S . -B build
cmake --build build
./build/lab1

Запуск тестов:

ctest --test-dir build --output-on-failure
